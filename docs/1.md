### Phần 3 – System Design & Implementation (BE/AI)

**⏱ 4–5 phút – 🎞 6–7 slide**

Phần này bạn show “bộ máy” bạn build:

1. **High-Level System Architecture (Figure 11)**

   * 1 slide hình kiến trúc tổng thể: client → API Gateway (FastAPI) → LangGraph Orchestrator → vLLM + PostgreSQL + Qdrant + Redis + Celery workers.

2. **Technology Stack**

   * 1 slide riêng:

     * FastAPI, LangGraph
     * vLLM + Qwen-8B, Qwen-Embedding, Reranker
     * PostgreSQL, Qdrant, MinIO, Redis, Celery
     * Hạ tầng GPU (dual RTX 4090)

3. **Core Infrastructure & AI Serving**

   * 1 slide giải thích vai trò từng khối:

     * PostgreSQL: user, conversations (ACID)
     * MinIO: lưu file
     * Qdrant: vector search, single collection + metadata
     * Redis: cache + rate limit + Pub/Sub (WebSocket).

4. **Data Processing Pipeline (Figure 12)**

   * 1 slide hình pipeline: ingest → extract → chunk → embed → index
   * Nhấn: Markdown-aware chunking, 1800 chars, 10% overlap, batch embedding, transactional index vào Qdrant.

5. **Multi-Agent Graph – Implementation (Figure 13 + agent list)**

   * 1 slide: mô tả Main Graph, Normal/Thinking Mode graphs, subgraphs (Simple Search, SQL Query…).
   * 1 slide: liệt kê nhanh các **8 agents** chính: Citation, Summary, Response, Verification, QAC, … + 1–2 dòng role cho mỗi agent.

6. **Security, Performance & Observability**

   * 1 slide cuối phần bạn:

     * Authentication, rate limiting ở API Gateway
     * Async + background jobs (Celery) để tránh timeout
     * Caching nhiều lớp với Redis
     * Logging/tracing (nếu bạn có dùng tools như LangSmith/LangFuse thì nhắc nhẹ).

> 6–7 slide x ~40 giây/slide ≈ 4–5 phút.
